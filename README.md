# Hi, I'm Elvis Ariel Miranda 👋

I am a Tokyo-based **Full-Stack & AI Systems Engineer** with 5+ years of experience building high-performance web applications, secure local AI infrastructure, and event-driven systems for global teams.

My current focus is on privacy-first developer tools, local LLM workflows, RAG pipelines, and dependable self-hosted infrastructure. I also care deeply about frontend performance: a recent React/Vite optimization reduced unnecessary re-renders by **60%**.

## What I build

- **Local AI systems** - event-driven orchestration, document ingestion, OCR, embeddings, vector retrieval, and local LLMs.
- **Production web applications** - React, Next.js, Astro, Node.js, Python, and .NET across healthcare, fintech, enterprise security, and e-commerce.
- **Reliable engineering platforms** - Dockerized Linux environments, CI/CD, testing strategy, and secure self-hosted services.
